# 말랑모아 성장 목표

사용자가 원하는 종이 스퀴시 도안을 가장 쉽게 찾는 사이트를 목표로 한다. 검색 1위 달성은 배포나 SEO 설정 완료와 별개이며 관측 자료 없이 달성으로 판정하지 않는다.

## 2026-10-23 첫 개선

- 251 → 266개 도안, 외부 제작자 5 → 6곳. 로사찡의 산리오·라부부, 그리피피의 미니북·유니콘, 룡룡쌤의 포켓몬·소품을 검토해 추가.
- 원문 링크와 원격 미리보기만 제공. 원본 도안 파일은 재배포하지 않는다.
- 무료/유료/요금 원문 확인과 스퀴시북 필터를 교차 적용. 확인하지 못한 형태는 추측하지 않는다.
- 3개 언어, 828개 indexable URL. 이 숫자는 Google 색인 수가 아니다.
- 매일 06:23 KST 갱신. Hyeriming 목록 자동 발견, 다른 검토된 도안은 링크와 미리보기 확인. 추가로 승인된 3개 제작자 RSS에서 신규 후보를 매일 발견해 검토 큐에 보관한다. 새 글 공개는 원문 확인과 다국어 검토 후 진행한다.
- 개별 출처 실패 시 마지막 정상 메타데이터 보존. 404/410과 접근 차단·일시 장애 구분. 부분 실패를 freshness.json 및 페이지에 표시. 단일 실패로 다른 출처 확인을 중단하지 않는다.

## 후속 우선순위

1. 허용된 RSS에서 신규 후보 발견 → 중복 검사 → 실제 출력 파일/원문 확인 → 다국어 검토 후 게시하는 큐. 후기나 일반 완제품을 도안으로 자동 게시하지 않기.
2. 따니네·옐로우·메이크잇·토림 등 추가 원문 검토. 자동 접근 제한은 우회하지 않고 수동 검토 상태로 구분.
3. 캐릭터별 동의어, 무료 도안 컬렉션, 제작자 페이지, 설명·준비물·출력 팁을 근거 있는 범위에서 확충.
4. 검색 결과 없음 비율, 제작자 원문 방문, 찜하기를 동의 기반 GA4로 측정. 검색어 원문은 전송하지 않는다.
5. Search Console에서 이 서브도메인만 대상으로 클릭·노출·CTR·평균 게재순위·색인 상태를 주 단위 비교. GA4의 사용자/세션과 이벤트 수를 구분한다.

## 성과 판정

우선 주간 검색 클릭 증가와 원문 방문 전환을 확인한다. 핵심 검색어(종이 스퀴시 도안, 무료 스퀴시 도안, 스퀴시북 도안, 캐릭터별 도안)의 노출·클릭·순위를 기간/국가/기기와 함께 기록한다. 평균 게재순위 1은 모든 사용자에게 항상 1위라는 뜻이 아니다. GEO는 실제 AI 답변의 출처 링크를 별도 관측해야 한다. 아직 유기적 유입, 1위, AI 인용 성과는 확인되지 않았다.

## 상세 페이지 중심 탐색

2026-10-23 사용자 방향 수정: 홈/컬렉션/검색 카드는 모두 자체 상세 페이지로 이동한다. 외부 도안 상세는 제작자 미리보기, 요금/형태/확인일, 브라우저에 저장되는 준비물 체크리스트, 일반적인 출력·조립 준비, 관련 도안을 제공한다. 실제 파일과 제작자 고유의 상세 과정이 필요할 때 하단 원문 버튼으로 이동한다. 일반 안내를 검증된 개별 도안 조립법으로 표현하지 않는다.
